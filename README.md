# Dictée flash

Petite appli pour iPad : l'élève regarde un mot quelques secondes, puis l'écrit de mémoire sur sa feuille. À la fin, il corrige avec la liste.

**Ouvrir l’application : https://ludo1104-rp.github.io/dictee-flash/**

- Le professeur colle sa liste de mots (Word, Excel…) ou touche « Mots au hasard » (400 mots de base pour les 8-9 ans).
- Préparation en 3 étapes : les mots, le rythme, l'affichage et le son.
- 7 polices au choix (cursive Marelle, bâton, OpenDyslexic…), style Couleurs ou Simple, 3 tailles de texte.
- Les réglages restent enregistrés sur l'appareil.
- Tout est dans `index.html`.

Version 1.4 — Application produite par IA à partir d'une application créée par Angelo Malaguarnera avec Gemini. Des erreurs peuvent survenir.
Application développée par Claude AI sous la supervision de Ludo (@rprof_1).
